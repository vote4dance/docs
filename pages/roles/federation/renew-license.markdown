# Starting a new license season

Licenses are not renewed: dancers and clubs apply again each season. Work through this page at
each rollover: check your setup before the season, tell clubs and dancers what to do, then work the
approval queue during the rush.

## There is no renew button

A license is not renewed in place: **you apply again for the new season**. The old one stays in
history and turns **Expired** when its validity window closes. The new one is a fresh application
that goes through the same route and the same four checks as the first.

A dancer blocked at registration is told "A required federation license has expired or is for a
different season — renew it for this season."

Plan around two consequences:

- **Nothing carries over.** Approval from last season does not shorten this season's approval, and
  a club approval or a payment is needed again.
- **The season year is the thing to get right.** A license for the wrong season is as useless as an
  expired one, and it is the most common mistake in a rollover.

## Before the new season

1. **License items.** Check each item for the new season: price, status, maximum uses per season.
   Switch off items you no longer offer, so applicants do not pick them. See
   [Setting up licenses](/federation/getting-a-license/).
2. **Class mappings.** Check that each class's **License rules** still require the right items.
3. **Club approvals.** Approve new clubs early. A pending club blocks every license its dancers
   apply for. See [Approving clubs](/federation/joining-a-federation/).
4. **Stripe.** Check that it is still connected.
5. **Age groups and promotion rules.** Make them final, then run the age-up batch. See
   [Age moves](/federation/age-moves/).

## Tell clubs and dancers

1. Licenses are applied for again each season. Nothing carries over.
2. Which items they need, and who applies: the dancer or the club.
3. When applications open, and how long approval takes you.

Point dancers to [Renewing for a new season](/dancer/getting-a-license/#renewing-for-a-new-season)
and clubs to [A new season](/school-club/getting-a-license/#a-new-season).

## During the rush

1. Work the **Needs your approval** queue. Rows tagged **Blocked** are waiting on a club you have
   not approved.
2. Use bulk approval for the ready rows. It skips licenses held by unapproved clubs.
3. Watch for applications on the wrong season year. A pending application can be deleted and made
   again.
