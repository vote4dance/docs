# Class questions at an event

You do not move couples between classes. Class moves happen automatically from promotion points,
or by hand at the federation, and registration only lets a couple register for the class it is in.

## How class moves work

1. Every entry earns promotion points for its placement.
2. When the organizer **closes** the competition, the points are added up per couple.
3. A couple that reaches its class's limit moves up at once, and the move is recorded.

So a couple's class can change after an event closes, not during it. See
[Promotion points](/federation/progression/).

## What this means for you

- **Correct results before the competition is closed.** Closing is what sends the points to the
  federation. See [Creating and getting rankings](/scrutineer/creating-and-getting-a-ranking/).
- **Check person numbers.** Points are matched to couples by them. A wrong number creates a
  duplicate couple with the points split.
- **A couple in the wrong class on the day:** decide with the organizer, and the federation's
  representative if there is one, before the class starts.
- **A class dispute after the event:** it belongs to the federation. They can move a couple by
  hand, and every change records a reason.
