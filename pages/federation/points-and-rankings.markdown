# Points and rankings

Four features use points or produce a ranking. Each does something different to a competitor: a couple, a solo dancer, a duo or a group. Many of these screens, and the messages dancers get, say *team* for the same thing.

| | What it is | What it does to a competitor | Where you set it up |
|---|---|---|---|
| [Promotion points](/federation/progression/) | Points earned at each competition, paid from a points table and added up per class. | Moves them to the target class at the promotion threshold, when a competition is closed. | The class level's federation rules: `Structure → (division) → Class Levels → Federation rules` |
| [Closing a class at points](/federation/class-point-limits/) | A limit on a competitor's season points, per class level. | At the limit, the competitor can no longer enter that class level. The next level up stays open. | **Class closes at points** in the rules of a division, discipline or category |
| [Entry rules and the season ranking](/federation/season-ranking/) | Entry rules for a competition level, such as a championship, and a public ranking of season points per age group. | With too few or too many points, or too few competitions danced, a competitor cannot enter. The ranking only shows the points. | Entry rules: `Competition Levels → Federation rules`. Ranking: **Publish the season ranking** in the division's rules |
| [Federation Rankings](/federation-rankings/) | A list built from results by a formula you set per ranking. | Orders the list. It moves nobody between classes. | The division's **Ranking** section under `Structure` |

The first three all use the points that the [promotion points table](/federation/progression/#setting-it-up) pays, so set that table first: a limit locks nothing without it.

Ranking points are separate. A ranking that ranks by points has its own **Ranking Points** table. If your rulebook uses one scale for both, set it in both places.

## Counting only the best results

Three of the features can count a competitor's best results instead of all of them, and each has its own setting:

| Feature | Counts | Setting |
|---|---|---|
| Promotion points | Everything earned since the competitor joined the class. There is no best-N. | None |
| Closing a class at points, entry rules and the season ranking | The best results of the season | **Results that count**, in the rules of the federation, a division, a discipline or a category |
| Federation Rankings | The best results in the ranking's time window | **Window mode** and **Take best count** on the ranking |

So **Results that count** never changes when a competitor is promoted. For a rulebook that promotes on the best results of a season, see [Promotion on the best results of a season](/federation/progression/#promotion-on-the-best-results-of-a-season).
