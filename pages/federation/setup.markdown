# Set up your federation

A new federation is set up in this order. Each step builds on the ones before it.

1. **Staff.** Everyone signs in with their own account. Add your colleagues and give each a role, with at least two Owners. See [Federation Staff Roles](/federation/staff-roles/).
2. **Federation details and Stripe.** Fill in the details under `Federation → Settings`, and connect Stripe if any license will cost money. See [Federation settings](/federation/settings/).
3. **Structure.** Create divisions, disciplines, categories, age groups, class levels and classes. Rules, licenses and rankings all attach to them. See [Divisions and disciplines](/federation/divisions/).
4. **Judging.** Check that the judging setups your rounds need are listed. Vote4Dance support adds or changes them. See [Judging](/federation/judging/).
5. **Rules.** Set age category rules, the round setup and the season start. See [Federation Rules](/federation-rules/) and [Age moves](/federation/age-moves/#before-the-first-run).
6. **Points.** If competitors move up on points, set the points table and the class ladder. See [Points and rankings](/federation/points-and-rankings/).
7. **Licenses.** Add license items and map them to classes. Divisions, disciplines and classes must exist first. See [Setting up licenses](/federation/getting-a-license/).
8. **Clubs.** Approve the clubs that apply, and allow license issuing where a license must name a club. A pending club blocks every license its dancers apply for. See [Approving clubs](/federation/joining-a-federation/).
9. **Rankings.** Create each ranking in its division and add its classes. See [Federation Rankings](/federation-rankings/).
10. **Public page.** A new federation has every public section off. Turn on the ones you want. See [Public page](/federation/settings/#public-page).

Competitions need no setup on your side: an organizer chooses your federation when creating an event, and it appears on [Competitions](/federation/competitions/).
